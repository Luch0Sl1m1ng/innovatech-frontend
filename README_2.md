# InnovaTech - Interfaz de Usuario (Frontend)

Interfaz moderna desarrollada para interactuar con los microservicios de Ventas y Despachos.

## 💻 Características
* **Nginx**: Servidor web de alto rendimiento para contenido estático.
* **Dockerizado**: Imagen ligera basada en Alpine Linux.
* **Integración**: Conexión directa con la API Gateway/Microservicios en AWS.

## 🔧 Configuración de Producción
El frontend está configurado para escuchar en el puerto **80** y comunicarse con los backends mediante la IP elástica de la instancia EC2.
